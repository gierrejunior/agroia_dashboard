# Dados originais

A demo usa `data/predicoes_demo_light.geojson`, gerado a partir do GPKG atualizado `predicoes_consolidadas_BA(1).gpkg`.

O GeoJSON leve contém todos os 9.976 talhões, com geometrias simplificadas para uso no navegador/GitHub Pages.

Campos usados:

- `cod_mun`
- `municipio`
- `fid_mask`
- `inf_safra1`
- `inf_safra2`
- `mb_safra1`
- `mb_safra2`

O GPKG original não foi incluído neste pacote leve para evitar peso desnecessário no GitHub Pages.
